# Technology Stack

This is a high-level overview of the technology stack and tools used.

## Technologies

| Layer | Technology | Reason |
| ------- | ------------- | -------- |
| **Frontend Framework** | TypeScript + React (Next.js) | Single responsive web app for both patient and doctor; modern web tooling and fast iteration |
| **Version Control** | GitHub | Centralized repo for code and documentation |
| **Design Tools** | MS Word prototypes | Visual prototypes and user flows |
| **Testing** | Jest + React Testing Library | Industry standard for React/Next.js web applications |
| **Development Tools** | Visual Studio Code | Most used frontend dev tool |
| **Debug** | Chrome DevTools | Quick to trace and identify errors |
| **Hosting & Deployment** | Vercel.app | Most used hosting environment for Next.js |
