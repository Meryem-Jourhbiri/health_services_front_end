# Milestone 2 – Profiles and Availability Integration

This milestone delivers profile management for patients and doctors along with the first pass at doctor availability scheduling. The focus is on connecting profile and availability UI to backend endpoints, building reusable dashboard navigation, and ensuring authenticated flows are consistent with the backend contract.

## Completed

- Created reusable navbar for doctor and patient dashboards.
- Added tests to include navbar routing.
- Aligned the frontend auth layer to the backend and expanded Sign-up to match backend requirements.
- Connected Sign-up, Login, Email verification and password reset to the backend API.
- Added authHeaders to allow frontend/backend JWT integration.
- Added 'Create', 'Edit', and 'Display' of patient profile and connected it to the nav menu.
- Hooked up the patient profile to the backend API.

## Not completed

- Connect verify email to registration and backend API
- Connect forgot and reset password to backend API
- Doctor profile management
- Doctor Availability
